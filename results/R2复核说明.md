# PolymerBenchmark2026：公开结果对应的 R² 恢复

结论：可以用现有公开数据恢复这张 scaling 汇总表对应的 R²，而且无需重新训练模型。本次已实际完成计算。结果是公开逐折误差的代数恢复，不是本次重新训练得到的新实验结果，也不是独立验证原模型预测。

- 提交：83655bc25901a8cabe3a1e5474b7ec26f01b919f；2026-11-08 查询 GitHub main 与用户提供 ZIP 一致。
- 输入结果：scaling_results/all/scaling_results_detailed.csv 和 scaling_results_aggregate.csv。

- 共补充 232 行汇总结果、1160 行逐折记录。图模型仅公开测试集误差，因此没有替它们编造训练集或验证集 R²。

## 计算口径

对每个条件、训练规模、模型、fold、split，读取对应的真实标签 y：

R² = 1 − SSE / SST = 1 − MSE / Var(y, ddof=0)

优先使用公开逐折 MSE；图模型未提供 MSE 时，使用该折 RMSE 的平方。随后对 5 折 R² 求算术平均及总体标准差（ddof=0），与原表汇总方式保持一致。

不能直接对 rmse_mean 平方后用全数据方差换算 R²。各折测试标签分布不同，必须逐折计算。这里也没有把重复随机划分的预测拼成一个整体 R²。

原始训练集为公开 train_pool 的前 N 行；验证/测试集取公开 val/test 索引。polyBERT 的原代码将标签存为 float32，再以 float64 计算指标，本次恢复保留这一转换。其他模型使用 float64 标签。

2. 10 个 canonical 数据文件 SHA-256 均与公开 manifest 完全一致。
3. 官方 manage_scaling_indices.py verify 通过全部 10 个索引包，包含 50 个折划分。
4. 校验各折索引完整、不重复、不交叠；逐条核对公开结果的样本数。
5. 用详细记录重新汇总 RMSE，均值/标准差与原 aggregate 表一致；每组折数均为 5。

## 文件

- test_r2.csv：116 行测试集汇总，优先查看。
- scaling_results_aggregate_with_r2.csv：保留原汇总列，追加 r2_mean、r2_std、r2_n_folds。
- scaling_results_detailed_with_r2.csv：逐折 R²、标签方差、使用的 MSE、样本数核查及精度口径。
- verification.json：数据哈希及验证摘要。
- recover_r2.py：可重运行的恢复脚本。

## 重运行

在原仓库副本中，用含 numpy、pandas、rdkit==2025.9.6 的 Python 环境执行：

```sh
python Datasets/Dataset_construction_scripts/OMers_convert_jsonl.py
python Datasets/Dataset_construction_scripts/manage_scaling_indices.py verify
python /path/to/recover_r2.py /path/to/PolymerBenchmark2026 /path/to/results
```

本次版本：Python 3.12；具体包版本见 environment.txt。恢复 R² 不需要 polyBERT 权重、GPU、模型检查点或原始预测文件。

## 使用边界

原始逐样本预测并未公开，因此本次不能独立核实作者预测是否正确，也不能恢复预测值。数值精度受公开误差的小数精度及已公开评估实现约束。建议表述为“依据公开逐折 RMSE/MSE、经校验的标签和固定划分恢复的 R²”。若要声称独立重训练复现，应另行训练，并同时对照原 RMSE。
